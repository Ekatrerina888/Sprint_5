# Автоматизация пользовательских сценариев на сайте Stellar Burgers

**Сайт:** `stellarburgers.education-services.ru`  
**Язык:** Python  
**Библиотека:** Selenium

## Цель проекта

Написать набор автоматизированных тестов (кейсов) для проверки функциональности личного кабинета и основных переходов на сайте.

## Проверяемые сценарии

### 1. Регистрация и валидация

- **Успешная регистрация**  
  Проверяется заполнение обязательных полей: «Имя» (не пустое), корректный формат Email (`логин@домен`), пароль (не менее 6 символов).  
  **Файл:** `ok_password_1.py`                                     
- **Ошибка для некорректного пароля**  
  Валидация при вводе слишком короткого пароля.  
  **Файл:** `error_password_2.py`

### 2. Сценарии входа в личный кабинет

Проверены различные пути для входа (логина) пользователя:
- Вход по кнопке «Войти в аккаунт» на главной странице (`Log_account_3.py`).
- Вход через кнопку «Личный кабинет». (`personal_account_4.py`)
- Вход через кнопку в форме регистрации. (`button_registration_form_5.py`)
- Вход через кнопку в форме восстановления пароля (`button_password_recovery_form_6.py`).

### 3. Навигация и переходы

- Переход по клику на «Личный кабинет» (`Go_to_personal_account_7.py`).
- Переход по клику на «Конструктор» (`Transition_personal_account_designer_8.py` )
- Переход по клику на логотип Stellar Burgers (`Transition_personal_account_logo_8.py`).

### 4. Выход и разделы каталога

- Выход по кнопке «Выйти» в личном кабинете (`Log_out_account_9.py`).
- Проверка переходов к разделам каталога: «Булки», «Соусы», «Начинки»  ( `Section_Constructor_10.py`).

### 5. Инфраструктура тестирования

- `test_credentials.csv` — файл для хранения учётных данных (логины/пароли) зарегистрированных пользователей для повторного использования в тестах входа.
- `test_data.py` — служебный модуль с функциями генерации тестовых данных (случайные имена, email, пароли) и методами сохранения/загрузки данных из CSV.
